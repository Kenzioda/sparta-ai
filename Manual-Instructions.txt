S.P.A.R.T.A — MANUAL INSTRUCTIONS
====================================
Super Personal Assistant for Real-time Tactical & Autonomous

PREREQUISITES
-------------
- Node.js 18+ or Bun 1.3+
- opencode CLI installed (npm install -g opencode or via your package manager)

INSTALLATION
------------
1. Install opencode if you haven't already:
     npm install -g opencode

2. Clone this repo or copy the sparta-ai files to your opencode config:
     git clone https://github.com/your-org/sparta-ai.git
     cd sparta-ai

3. Install dependencies:
     npm install
     # or
     bun install

4. Configure opencode to use the Sparta agent:
     Copy or symlink .opencode/ to your opencode config directory
     or set the OPENCODE_CONFIG_PATH environment variable to point here

USAGE
-----
Launch opencode with the Sparta agent:
     opencode --agent sparta

Or set Sparta as your default agent in opencode.jsonc.

ARCHITECTURE OVERVIEW
---------------------
The Sparta system extends opencode with:
  - A master agent prompt (packages/opencode/src/agent/sparta.txt)
  - A plugin that registers the Sparta agent (packages/core/src/plugin/agent/sparta.ts)
  - Compression engine for context optimization (packages/opencode/src/compression/)
  - Sandbox isolation layer (packages/opencode/src/sandbox/)
  - Specialized tools: stealth-browser, hierarchy-delegate, sandbox, signin
  - UI themes for terminal (TUI) and desktop
  - Full skills database (specs/storage/SPARTA-SKILLS.md) with 41 faculties

TIER SYSTEM
-----------
- Master (you):          High-intelligence model, decomposes and delegates
- Senior Helper:         Mid-tier subagent for analysis and code review
- Junior Helper:         Budget subagent for search and data gathering
- Worker:                Direct tool calls for simple operations

  packages/ui/src/theme/themes/sparta.json     - Desktop UI theme
  specs/storage/SPARTA.md              - Full identity specification
  specs/storage/SPARTA-SKILLS.md       - 376 skills across 41 faculties
  skills/sparta/SKILL.md               - Skills overview

SECURITY
--------
- Faculty-driven risk model with 5 levels (Low to Critical)
- Automatic disclaimers for regulated domains (medical, legal, financial)
- Session-scoped permissions, never persisted across sessions
- Destructive action guard requires explicit user confirmation
- Runaway reasoning cap (7 depth levels) with auto-summarization

S.P.A.R.T.A — MANUAL INSTRUCTIONS
====================================
Super Personal Assistant for Real-time Tactical & Autonomous

INSTALLATION
------------
Option A — Standalone Binary (recommended):
  Download the installer for your OS from:
    https://github.com/Kenzioda/sparta-ai/releases

  Windows: Run sparta-*-win-x64-installer.exe
  macOS:   Extract sparta-*-mac-*.tar.gz and run install.sh
  Linux:   Extract sparta-*-linux-*.tar.gz and run install.sh

  After install, type 'sparta' in terminal or double-click desktop icon.

Option B — Via npm (requires Node.js 18+):
  npm install -g opencode sparta-ai
  sparta

Option C — One-liner web install:
  Windows PowerShell:  irm https://sparta.ai/install.ps1 | iex
  macOS / Linux:       curl -fsSL https://sparta.ai/install.sh | bash

USAGE
-----
  sparta                    Launch interactive terminal UI
  sparta --agent sparta    Launch with Sparta agent (default)

ARCHITECTURE OVERVIEW
---------------------
The Sparta system extends opencode with:
  - Agent definition via .opencode/agent/sparta.md
  - Compression engine for context optimization (src/reference)
  - Sandbox isolation layer (src/reference)
  - Specialized tools: stealth-browser, hierarchy-delegate, sandbox, signin
  - UI themes for terminal (themes/tui) and desktop (themes/ui)
  - Full skills database (specs/storage/SPARTA-SKILLS.md)

TIER SYSTEM
-----------
- Master (you):          High-intelligence model, decomposes and delegates
- Senior Helper:         Mid-tier subagent for analysis and code review
- Junior Helper:         Budget subagent for search and data gathering
- Worker:                Direct tool calls for simple operations

UNINSTALL
---------
  Windows: Run the uninstall.bat in the install directory, or use
           Apps & Features in Settings.

  macOS:   sudo rm -f /usr/local/bin/sparta
           sudo rm -rf /usr/local/lib/sparta
           rm -rf ~/Applications/S.P.A.R.T.A.app
           rm -f ~/Desktop/S.P.A.R.T.A.app

  Linux:   sudo /opt/sparta/uninstall.sh

  npm:     npm uninstall -g sparta-ai opencode

SECURITY
--------
- Faculty-driven risk model with 5 levels (Low to Critical)
- Automatic disclaimers for regulated domains
- Session-scoped permissions, never persisted
- Destructive action guard requires user confirmation

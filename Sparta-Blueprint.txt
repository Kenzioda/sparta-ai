S.P.A.R.T.A — ARCHITECTURAL BLUEPRINT
========================================
Super Personal Assistant for Real-time Tactical & Autonomous

1. SYSTEM OVERVIEW
------------------
S.P.A.R.T.A is a hierarchical multi-agent system built on the opencode
engine. It extends opencode with a tactical command structure, domain-
expert skills database, and safety-governed deployment framework.

4. AGENT SYSTEM
---------------
  Agent loaded via .opencode/agent/sparta.md (openocode config-agent system)
  Frontmatter: { mode: "primary", color: "cyan" }
  Body: system prompt defining:
    - Tier system (Master/Senior/Junior/Worker)
    - Decision framework (simple/medium/complex)
    - Tool usage patterns
    - Guardrails

5. INSTALLATION METHODS
-----------------------
  a) Standalone binary (.exe, .dmg, .tar.gz)
     - Engine compiled via Bun.build({ compile })
     - Sparta config packaged alongside
     - Installer creates desktop shortcut + PATH entry

  b) npm package
     - bin/sparta sets OPENCODE_CONFIG_DIR and runs engine
     - Requires opencode engine from npm (peer dependency)
     - Sparta config delivered via npm files

  c) Web installer (one-liner)
     - Detects OS/platform
     - Downloads correct release from GitHub
     - Runs platform installer

6. SECURITY MODEL
------------------
  Risk Level Classification:
    Critical:  Medical, Legal, Emergency (disclaimers required)
    High:      Finance, Transportation, Real Estate
    Moderate:  Engineering, Sciences, Trades
    Low:       Arts, Business Ops, Media

  Universal Safeguards:
    - Dynamic guardrails calibrated to capability limits
    - Session-scoped permissions (never cross-session)
    - Destructive action guard (user confirmation required)
    - Runaway reasoning cap (7 recursive depth levels)
    - Faculty-driven risk model (41 faculties)
